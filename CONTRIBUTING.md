# Contributing Guide

We welcome contributions from the Java and Spring communities.

## How to Contribute

1. Fork the repository
2. Create a feature branch
3. Add or improve a question
4. Ensure the writing follows the template
5. Include citations for all facts or sourced material
6. Open a pull request with a clear summary

## Standards

- Questions should be specific, interview-relevant, and clear
- Each question should include the answer or answer outline
- Use the provided template structure
- Prefer official documentation and public sources as references
- Include a difficulty label and topic tag

## Good Contributions

- Better explanations of common Java/Spring interview questions
- Real-world examples and code snippets
- Senior and staff-level questions with trade-offs
- Fixes to outdated or incorrect content

## Quality Bar

Before submitting, verify:
- spelling and grammar are clean
- code examples are valid Java
- the reasoning is technically accurate
- the sources are correctly cited
