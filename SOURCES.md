# Sources and Attribution

This project builds on official documentation, open-source educational content, and established interview-prep resources.

## Primary Official Sources

1. Oracle Java SE Documentation  
   URL: https://docs.oracle.com/en/java/  
   Use: Core Java, JVM, generics, collections, exceptions, concurrency  
   Notes: Primary source for Java language and standard library behavior

2. Spring Framework Documentation  
   URL: https://spring.io/projects/spring-framework  
   Use: Dependency injection, bean lifecycle, AOP, MVC, transaction management  
   Notes: Official source for core Spring concepts

3. Spring Boot Documentation  
   URL: https://spring.io/projects/spring-boot  
   Use: Boot basics, auto-configuration, properties, Actuator, production concerns  
   Notes: Primary source for Spring Boot questions

4. Spring Security Documentation  
   URL: https://spring.io/projects/spring-security  
   Use: authentication, authorization, JWT, security configuration  
   Notes: Official guidance for security topics

5. Jakarta Persistence / JPA  
   URL: https://jakarta.ee/specifications/persistence/  
   Use: JPA entity mapping, persistence semantics, transactions  
   Notes: Official specification for persistence APIs
